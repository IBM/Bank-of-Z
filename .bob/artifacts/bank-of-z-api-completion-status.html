Summary: 3 frontend pages are fully broken (account-create.html, account-delete.html delete action, customer-details.html search) because their corresponding API operations (POST /accounts, DELETE /accounts/{id}, customer name search) are not in the OpenAPI spec. The GET /accounts endpoint exists in the spec and api.js but has no frontend page. IMS account detail and transaction pages are not separately built — they share CICS pages via routing logic.
